Alignment is semantic rather than whole-file equality, except where the [shared public policy procedure](../../skills/.domfiles-skill-development/references/public-skill-portability.md#include-shared-public-policies) requires a verbatim template copy. Fallbacks and mirrors retain each consuming workflow’s scope, terminology, links, and approval, delivery, and execution boundaries. The approval family shares instruction source requirements, not a grant scope or lifetime.

Review flow requires each reviewer to state whether any findings remain standing, and GitHub CLI requires that statement in review assignments. Contribution flow requires that status before preparing commits or declaring readiness. Those requirements are independent public contracts, not mirrors of the global **Findings** policy.
