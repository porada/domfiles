# Full Review

A full review combines two independent reviews through `subagent-review-flow`.

## Resolve Scope and Authority

Resolve the target from the request and current task. Apply global **Review workflow requests** to direct invocations. A governing workflow route carries its established target and authority without granting additional effects.

Preserve explicit read-only or no-fix limits. Pass the established correction authority and selected scope into `subagent-review-flow`.

## Maintain Reviewer Continuity

Load `subagent-review-flow` before selecting execution interfaces. Use its lifecycle, retained-context, recovery, and completion requirements for both roles.

For later reviews of the same work, resume the latest valid conversations where permitted, including after an earlier review completed. Each requested full review covers the current target rather than only earlier findings.

Retain the required reviewer selection during continuation. If the existing cross-provider participant no longer matches the coordinator’s identity, or the required interface and settings cannot be preserved, report the specific mismatch and use the shared limited-review endpoint rather than substituting a different participant.

## Coordinate Resolution

Give both reviewers the same target and baseline. Run their read-only assessments in parallel when supported.

Use `subagent-review-flow` directly for assignments, consolidated findings, disputes, authorized corrections, re-review, and completion. Use `cli-subagent` only for its selected provider interface and execution requirements, preserving its recursion boundary.

Record resulting changes through the governing commit policy and apply global **Thread cleanup** when the reviewer conversations are no longer needed.
