# Choose the Implementation Model

Use the most recent Astra model available in the host’s catalog at thread creation unless the user chooses a model. Apply **Thread effort**. If the catalog has no Astra model for the default, or the user’s chosen model is unavailable, ask which model to use.

Name the provider, model, and reasoning effort in the handoff offer. Send the prompt only when the user’s acceptance or an existing grant covers its contents and the selected provider under **External services** and **Agent communication**.
