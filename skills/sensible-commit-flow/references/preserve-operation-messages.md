# Preserve Operation Messages

1. Resolve the repository, destination checkout and branch, source commits, and operation order. Record the destination’s starting `HEAD`, inspect the source patches and complete messages against the relevant destination history, and identify unrelated index and working tree state to preserve. Don’t substitute the destination’s uncommitted diff for the operation’s changes or proceed through an unrelated Git operation already in progress.
2. Preserve complete inherited cherry-pick messages and Git-generated merge messages by default, including bodies and trailers. Skip hunk grouping, and don’t apply message composition or authored message conventions to inherited or generated messages. Retain the entrypoint’s [message safeguards](../SKILL.md#preserve-message-constraints). Resolve an explicit message rewrite request during preparation rather than silently normalizing the existing message. If the request requires composing replacement wording, load [Compose Messages](compose-messages.md).
3. Add the exact operation and invocation, source commit IDs and order, destination and starting `HEAD`, intended changes, and expected parent relationships to the shared [execution baseline](commit-execution.md#confirm-commits). Identify inherited messages by their inspected source commits. For generated messages, retain a read-only preview when available or record the inputs from which Git will generate the message instead of inventing exact text. When shared confirmation requires presentation, put each complete inherited message or available generated preview in a blockquote without rewriting it, and otherwise state that Git will generate the message from the approved inputs.
4. During [Create Approved Commits](commit-execution.md#create-approved-commits), use the operation’s native preparation, command, and continuation flow rather than staging authored hunk groups or replacing it with freshly composed commits. For cherry-pick sequences, apply one source commit at a time. Add verification of expected parent relationships to the shared post-commit checks.
